# Estudos de HTML, CSS e JavaScript

Repositório dedicado aos meus estudos e práticas de desenvolvimento web. Aqui ficam organizados exercícios, exemplos e projetos feitos durante o aprendizado de HTML, CSS e JavaScript.

## Conteúdos

- **HTML**: estruturação de páginas e uso de elementos semânticos.
- **CSS**: estilos, layouts e construção de interfaces responsivas.
- **JavaScript**: lógica de programação e interatividade para páginas web.

## Organização

Os arquivos estão separados por assunto e prática. A pasta [`HTML`](./HTML) reúne os materiais relacionados aos estudos de HTML.

## Como visualizar

1. Clone ou baixe este repositório.
2. Abra a pasta do projeto no seu editor de código.
3. Para visualizar uma página, abra o arquivo `.html` correspondente no navegador.

## Objetivo

Praticar os fundamentos do desenvolvimento web, acompanhar minha evolução e manter os exercícios e projetos de estudo em um só lugar.
